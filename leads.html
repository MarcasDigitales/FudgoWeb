Gestión de prospectos

El panel original de prospectos dependía de Supabase para consultar, editar y eliminar registros. Esta versión estática no incluye una base de datos ni un servicio de autenticación.

Para reactivar esta sección se necesita conectar un backend seguro o un CRM. No es recomendable publicar un panel administrativo sin autenticación.
